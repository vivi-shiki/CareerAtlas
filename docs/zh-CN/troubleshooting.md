# 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 工作区跳转到登录 | 会话不存在或已过期，请重新登录；首页和文档仍公开。 |
| 无法确认经历 | 补齐标题、项目、类型、发生时间和个人行动，检查字段错误。 |
| 发布列表没有某条经历 | 确认当前草稿，并检查记录是否仍可用。 |
| 保存时提示来源已变化 | 其他编辑已通过版本检查。保留未保存文本副本，刷新、比较后有意识地重新应用。 |
| 发布要求重新预览 | 来源或选中字段有变化，重新生成并核对预览。 |
| 公开页面不可用 | 本人可能撤销了发布或来源，不能通过旧问答绕过权限。 |
| AI 控件不可用 | 运营者可能关闭了提供方或未为此用户/页面启用，请先手动操作。 |
| 本地 AI 一直等待 | 检查 `agent` 队列进程、提供方配置和服务端日志，不要在问题报告中暴露密钥。 |
| 练习消失了 | 只有明确保留的练习会在临时保存的 24 小时后继续保留。 |
| 界面换语言但正文没变 | 已保存记录和旧回答保留原语言，新草稿和导出另选目标语言。 |
| 无法下载翻译 | 核对译文，并勾选已检查的确认框。 |
| 列表看不到更早的 P1 数据 | 当前 P1 列表显示本人最近的 100 条记录。 |
| 本地文档返回 404 | 运行 `npm run build`，打开完整的 `/docs/<locale>/index.html` 地址。 |

## 报告问题

提供受影响流程、界面/内容语言、浏览器、复现步骤、预期结果和实际表现。使用虚构示例或对截图脱敏，不要附上 `.env`、bearer token、真实联系资料、私人经历或提供方密钥。

开发问题请附执行命令及脱敏错误。通过[本地设置](./development.md)和[技术架构](./architecture.md)定位相关进程。
