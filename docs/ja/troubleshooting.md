# トラブルシューティング

| 状況 | 確認・対処 |
| --- | --- |
| ワークスペースがログイン画面になる | セッションがないか期限切れです。再ログインしてください。ホームと文書は公開です。 |
| 経験を確定できない | タイトル、プロジェクト、種類、発生時期、個人の行動と入力エラーを確認します。 |
| 公開一覧に経験がない | 最新の下書きを確定し、記録が利用可能か確認します。 |
| 保存時に情報源の変更が表示される | 別の更新が先に保存されました。未保存文のコピーを取り、再読込・比較後に変更を適用します。 |
| 再プレビューが必要になる | 情報源や選択項目が変わっています。新しいプレビューを生成して確認します。 |
| 公開ページが利用できない | 公開や情報源が取り消された可能性があります。古い会話でアクセスを迂回しないでください。 |
| AI の操作が無効 | 運用者が無効にしたか、本人・ページが対象外です。手動で続けられます。 |
| ローカルの AI が待機したまま | `agent` ワーカー、提供元設定、サーバーログを確認します。報告にキーを含めないでください。 |
| 練習が消えた | 明示的に保持した練習だけが 24 時間の一時保存後も残ります。 |
| 言語を変えても文章が変わらない | 保存済み記録と過去の回答は元の言語です。新しい下書き・出力では対象言語を選びます。 |
| 翻訳をダウンロードできない | 翻訳を確認し、照合済みのチェックを付けます。 |
| 古い P1 データが一覧にない | 現在の P1 一覧は本人の最新 100 件を表示します。 |
| ローカル文書が 404 になる | `npm run build` 後、明示的な `/docs/<locale>/index.html` を開きます。 |

## 問題を報告する

対象の操作、画面と内容の言語、ブラウザー、再現手順、期待結果、実際の動作を記載します。架空の例を使うか画像を匿名化してください。`.env`、bearer token、実際の連絡先、非公開の職務記録、提供元の秘密情報は添付しないでください。

開発中の問題には、実行コマンドと秘密情報を除いたエラーを添えます。[ローカル設定](./development.md)と[技術構成](./architecture.md)から関連プロセスを確認できます。
